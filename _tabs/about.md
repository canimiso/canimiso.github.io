## name: canimiso (canibrain/蟹脳)

ゲーム好きの文系だけど**tech系が気になる系男子**。Debian/FreeBSDの入ったMini-ITX/玄箱HGで自宅サーバー経験あり。

メインPCは`Intel Core 2 Duo E6600 (2.40GHz)`→`Intel Core i5-3570K (3.4GHz, Ivy Bridge)`→`AMD Ryzen 7 5700X (3.4GHz-4.6GHz)`と順当にありがちで無難なCPUをチョイスしてきました。ゲーム好きですがGPUは買い時を逃してGeForce GTX 1070で止まっています。

2Dイラスト/ドット絵も少々嗜みます。※サイト内で出典記載のないイラスト・ドット絵は自作です。

小説は**氷と炎の歌**(ジョージ・R・R・マーティン) / **ウィッチャー**(アンドレイ・サプコフスキ) / **銀河英雄伝説**(田中芳樹) / **十二国記**(小野不由美) / 黄金を抱いて翔べ, 神の火, わが手に拳銃を, リヴィエラを撃て, 地を這う虫(髙村薫)あたりを読み込んでいます。**マリア様がみてる**(今野緒雪)も全巻持ってるぜ！

ゲームはFallout 3, NV, 4, Oblivion, Skyrim(Bethesda) / Terraria / Noita/ Path of Exile 1, 2 / Diablo 2, 3 / Torchlight 1, 2 / Grim Dawn / Core Keeper / Elin / Wizardry / Tales of Maj'Eyal などに熱狂。特に穴掘りゲームとハクスラ、3Dダンジョンに目がないです。

定期的に文房具にも沼ります。トラベラーズノート / 測量野帳 / ロルバーン / ほぼ日手帳 / M5手帳 / 万年筆 / LAMY / STAEDTLER など。今は**ダイソーのB6軟質カードケース**を装着した**ロルバーン Lサイズ**に**ユニボールONE**でメモするのが正義です。
